# 功能使用文档

更新日期: 2026-11-16. 本文面向消费者、商家和运营人员. 功能状态见[项目开发文档](项目开发文档.md), 环境搭建和故障排查见[项目维护文档](项目维护文档.md). 页面可操作与真实平台能力已验收是不同状态.

## 1. 使用前准备

商家需要配置自己的品牌、客服、商品图片视频、价格库存、正式协议和工艺规则. 演示示意图不能替代实物摄影, 空配置不能作为正式经营资料. 系统不会替商家猜测珍珠来源、产地、鉴定等级或生产长度.

消费者可游客浏览. 保存私人设计、下单、社区发布及个人资料操作需要主动登录; 协议更新时先阅读确认, 返回后自行重试原操作. 退出或切换账号后不复用上一账号的地址、优惠券、草稿或购买上下文.

### 商家后台快速入门

本机打开 `http://localhost:8888` 并登录. 首页按员工岗位动作和业务机构显示工作台入口及待办. 日常操作可点击对应待办直接打开处理队列.

| 要办的事 | 菜单入口 | 保存后核对 |
| --- | --- | --- |
| 设置客服与协议 | 客服与售后 → 商家服务、系统设置 → 协议与隐私 | 客服展示可用的联系方式, 两份协议显示已发布的版本. 改正文时先保存草稿再发布. |
| 发布或修改商品 | 商品与材料 → 商品管理 | 来源、品类、主图、SKU、售价、库存和上架状态齐全, 小程序可筛选并选择有库存的规格. |
| 设置DIY项链 | 商品与材料 → 定制配置、组件库存 | 项链模板开启, 选项有实物资料、价格及库存, 计长规则可用于报价. 先验一套可制作组合. |
| 处理订单、售后或退款 | 订单与制作 → 订单列表、客服与售后 → 售后服务或退款管理 | 履约录入物流, 客服登记和跟进售后, 退款负责人录入审核意见后单独执行. |
| 制作与质检 | 订单与制作 → 生产工单 | 冻结材料、尺寸和备注正确, 按审核、制作、质检、发货的状态推进. |
| 审核及回复运营事项 | 社区 → 社区管理或评论管理、客服与售后 → 会员反馈 | 社区和评价核对审核状态, 反馈核对未读状态和处理内容. |

### 员工账号与岗位工作台

1. 超级管理员在“系统设置 → 角色管理”为六个预设岗位选择业务机构. 按机构建立同岗角色时, 勾选所需父菜单、页面及操作, 复核职权后再批准委派. 超级管理员保留应急账号, 日常系统管理员使用个人账号.
2. 在“系统设置 → 员工账号”为每位员工单独开户, 填写员工资料、独立初始密码和岗位. 工作室归属由服务端确定. 可暂时留空岗位; 无业务授权时登录后工作台为空. 将用户名和初始密码通过受控渠道交给本人.
3. 员工首次登录后, 点击右上角“修改密码”. 登录页“修改密码”可在登录后直接进入改密窗口. 忘记密码时, 登录页会提示联系已有重置权限的管理员. 管理员核验身份后为该账号设置新密码, 原会话随即失效. 当前手机号或邮箱是员工资料, 自助验证码重置需要先完成绑定验证和消息渠道配置.
4. 多岗位员工可同时勾选多个角色. 在员工账号页的“权限来源”查看各角色、权限键及机构. 撤销角色后服务端对下一次请求重新校验, 停用账号后原会话随即失效.

左侧入口随岗位显示, 每次切换只打开当前页面. 订单详情、商品详情及编辑、员工新增及编辑可用面包屑或“返回列表”回到原筛选和分页, 也可刷新或使用浏览器前进后退. 员工及商品表单有未保存修改时会提示. 组织机构由应急管理员在“系统设置 → 角色管理 → 组织机构维护”处理.

| 岗位 | 工作台入口和待办 |
| --- | --- |
| 商品运营 | 商品管理、库存异常、DIY材料维护 |
| 履约／制作 | 待处理工单、待制作、待质检、待发货 |
| 客服／售后 | 待处理售后、客户反馈、待回复事项 |
| 退款负责人 | 待审核退款、待重试退款、待对账退款 |
| 社区运营 | 待审核社区内容 |
| 系统管理员 | 员工账号管理、角色管理、权限配置、系统审计 |

同一员工在两个机构分别负责商品和退款时, 退款队列只列出退款角色授权机构的记录. 起始没有业务归属的历史记录需要由负责人确认后回填. 已有环境的升级和授权步骤见[订单权限发布](项目维护文档.md#订单权限发布).

## 2. 商城与商品

首页、商品列表和个人列表读取失败时显示失败提示, 可按“重试”重新读取失败区块. 新品、热门、品牌、分类和搜索商品按20条分页, 滑到底部读取下一页; 加载失败保留已读取内容, 不跳过失败页. 切换筛选重新从第一页读取. 公开商品总数只统计未删除且在售商品; 打开不存在的分类会显示明确的分类错误, 可返回后重新选择.

1. 进入商城, 选择淡水/海水来源以及项链、耳饰、手链或戒指品类. 两个维度可组合筛选.
2. 打开商品查看真实图片、参数、详情和视频. 视频失败时可继续查看图片或联系客服.
3. 选择完整规格和购买数量, 核对规格对应的价格及可购买数量. 缺货或不存在的组合不可购买.
4. 加入购物车或立即购买. 提交失败保留选择, 根据提示重试; 网络不确定时先查看购物车或订单, 不连续重复操作.
5. 后台未补齐来源/品类的历史商品不会自动出现在新目录, 需由商家确认后维护.

## 3. DIY项链

材料只分珍珠、尾扣、配饰、链条四类; 贵金属、款式和尺寸属于材料属性, 不再提供旧分类入口. 真实可售材料和组合由商家配置, 同一种材料可以多次加入排列. 选择节点后可插入、复制、调序和删除, 支持撤回、清空和恢复.

二维预览按材料尺寸提供比例示意, 不代表实物光泽、颜色、工艺精度或试戴效果. 未知尺寸不会自动按候选区间中点填写. 实测颈围、目标成品长度、材料跨度参考和工艺成品估算分别查看, 不把规则参考或预览跨度直接用于生产.

保存到“我的设计”后继续编辑本人草稿. 同一草稿保存更新已有版本, 其他设备已修改时须处理冲突. 未完成尺寸或规则的草稿可以保存, 下单前必须补齐. 已下单设计进入订单流程, 不重复创建订单或改写冻结快照.

## 4. 尺寸与材料参考

首版使用公开尺寸资料和固定筛选规则, 无需配置云环境或模型额度. AI安排在下一版本. 登录后在DIY页填写选填的实测颈围(mm), 选择较短、中等或较长偏好, 点击“查看规则参考”. 这一字段同时用于后续设计报价, 不需要重复录入. 不采集身高体重来推算颈围.

结果列出可比较的常见长度、筛选理由、来源链接及核验日期. 未填写实测颈围时只提供通用比较值; 参考档位不大于颈围或超出商家可制作范围时会被排除. 没有交集时请调整偏好、用绳线试戴或联系商家, 系统不会补造长度或承诺合身. 厘米仅用于展示, 实测和生产字段统一为mm.

页面同时列出单项库存可用的材料候选, 不代表已经校验完整组合. 参考不会自动替换材料排列、颗数或目标成品长度; 请在材料库自行选择并重新获取服务端报价. 尺寸和工艺规则不完整时仍可保存草稿, 不能据此下单.

参考请求不另存身体画像, 不向第三方模型发送数据. 保存设计时实测尺寸仍随本人草稿、订单及工单保存以便制作. 参数变化、账号切换或离页会废弃旧参考; 请求失败保留设计并允许重试, 不影响手动设计.

## 5. 社区

社区分设计、成品、建议. 登录后填写内容并上传本人图片, 最多6张, 每张最多5MB. 设计分享须先保存本人排列并明确同意公开材料信息.

提交后为待审核, “我的分享”查看状态及说明. 只有审核公开的内容进入公共列表. 可以点赞、取消点赞和删除自己的分享, 没有评论、私信或加好友入口. 自行上传到文字和图片中的私人资料可能公开, 发布前自行核对.

运营在后台查看内容和图片, 审核通过、隐藏、删除或恢复时填写原因. 后台删除的内容可恢复到待审核, 重新审核后可公开. 作者自行删除的内容保留其删除状态. 人工审核和微信平台内容安全分别验收.

## 6. 购物车、订单和售后

购物车从商品页或“我的”进入. 选择商品、调整数量后核对服务端返回的金额, 失败不表示已保存. 无效规格、库存或下架商品需重新选择.

地址列表加载失败时点击提示重试, 加载期间或读取失败时不能选择旧地址. 编辑已有地址可直接保留原省市区; 修改地区时依次选择省、市、区并确认. 保存结果未确认时保留输入, 先返回列表核对, 避免重复新增. 收藏长按操作以后端实际结果为准, 失败后重新核对列表.

结算前确认收货地址、优惠券、商品数量及定制信息. 服务端复核价格、库存和条款版本. 支付客户端提示后以服务端订单状态为准; 支付或退款处理中先查询状态, 不根据页面动画判断资金结果.

“我的”查看订单、设计、地址、购物车、售后及协议. 在本人订单发起售后并查看处理进度. 新协议确认不应阻断已有订单查询、继续支付和售后履约; 新下单需要完成当前确认.

## 7. 商家商品维护

后台维护商品名称、来源/品类、参数、相册、规格、单价、库存和上下架状态. 直径上下限同时填写或同时留空, 单位mm, 不能把行业参考资料当作商品鉴定事实.

修改规格时核对每个组合及其价格库存, 保存后回到小程序验证展示和购买. 停用组合不改写既有订单. 源码已统一SKU契约并通过隔离数据库回归, 仍需完成部署和实际客户端链路验收后再作为已升级后台使用.

图片使用专用安全上传入口, 单张最多5MB. 商品视频独立上传, 最多30MB/60秒, 使用非分片H.264 MP4, 可附带AAC-LC音轨, 长边不超过1920、短边不超过1080. 不支持的文件须用自己的编辑工具导出兼容格式. 上传完成后再保存商品; 保存成功才对消费者展示. 服务端检查媒体容器声明, 不提供转码或完整内容审核保证.

## 8. 商家规则与客服

定制配置维护四类材料、尺寸、价格、库存、图层和启用状态. 每实例加价与单件耗用量分别维护, 商品支持名称搜索和翻页, 材料支持名称/代码搜索. 停用保留库存与历史引用. 配饰需明确选择“串接, 按实测跨度计长”或“悬挂, 不占项链周长”; 未确认不能启用. 悬挂不计周长并不代表预览与实物完全一致. 后台可下载客户112项候选模板, 包含67项珍珠规格、4项尾扣、14项暂定配饰及27项链材; 全部默认停用, 导入不会自动补真实库存. 0价格为未确认占位, 区间不是实测直径, 请填写实物资料后逐项核对启用. “戴妃皇冠”和“皇冠”作为不同暂定候选保留, 原始连写文本随模板提供. 导入会更新模板和同代码材料, 根据确认提示核对目标商品, 保留已有库存及其他未替换材料. 成品长度规则使用毫米表单, 包括制作方式、扣件长度、连接长度、加工缩短量、容差和成品范围. 参数由经营者实测确认, 不直接发布测试组合.

客服入口覆盖小程序业务页面. 后台填写自己的客服文字、联系方式、二维码或可用平台入口. 未配置时明确提示, 不填入参考商家的身份. 微信客服能力及合法域名须在实际账号验证.

## 9. 协议、履约和权限

新环境初始化包含用户协议和隐私政策正式首版(version 1). 经营者每次修改先保存为新草稿, 核对后发布递增版本; 已发布内容不被覆盖, 不能用空正文或演示文字替代. 经营者补充正式主体、联系方式或其他内容时同样升级版本. 用户确认记录和订单冻结版本可追溯; 历史订单没有凭据时系统不补造.

生产人员按审核、制作、质检、发货等允许状态操作工单, 核对冻结材料、尺寸和备注. 订单价格或材料后续变更不改写原生产依据.

后台角色按岗位授予最小权限, 服务端复核接口动作和对应机构. 支付前改价和发货各有独立权限. 退款审核先保存意见, 执行人按审核结论操作后系统才会处理退款. “重试退款”仅针对待重试记录, 可能按原退款号提交渠道. “对账并更新状态”查询渠道已有记录并同步状态.

## 10. 常见现象

支付结果页只有向服务端确认支付成功后才显示成功. 返回参数、微信付款窗口关闭或网络中断均不代表付款成功; 结果未确认时可主动重新查询, 勿连续重复付款. 订单取消、确认收货、删除地址和取消收藏均需等待当前操作完成; 网络不确定时先刷新核对状态. 取消或未发货退款如遇商品库存恢复失败, 整个操作会回滚并提示失败, 不会出现订单已取消但库存未恢复的部分成功状态.

| 现象 | 处理 |
| --- | --- |
| 商品不在商城目录 | 核对在售状态及来源/品类, 不直接改数据库发布 |
| 规格缺货或不可选 | 检查对应组合的库存, 选择其他组合或联系商家 |
| 菜单乱码或页面仍旧 | 维护人员核对运行版本及缺失迁移, 仅更新源码不会升级运行实例 |
| 提示该商品暂未开放定制 | 材料迁移已停用旧分类模板; 商家在后台补齐四类真实材料、尺寸、价格、库存及工艺后再发布 |
| 协议页没有正文或无法勾选 | 新库应含正式首版; 已有库核对发布版本, 商家后续修改须保存并发布递增版本, 不使用演示正文授权登录 |
| 设计无法下单 | 补齐尺寸和商家工艺规则, 查看服务端具体校验提示 |
| 视频不可播放 | 查看图片, 核对文件格式、访问域名及微信真机表现 |
| 参考不可用或无长度交集 | 核对实测颈围、偏好及商家制作范围, 可重试或继续手动设计 |
| 操作网络失败 | 先确认服务端结果, 写操作不盲目连续重试 |


商品上架资料填写统一规则: 新建或修改上架商品时, 均须明确选择珍珠来源和成品品类, 不能用空字段沿用旧商品规则. 尺寸或产地未知时不编造数值; 不能满足上架条件时先保持下架并补齐真实资料. 地址列表、保存、详情和删除接口保持一致, 地址身份只取当前登录用户, 不接受客户端传入其他用户身份.


收货地址编辑: 个人中心与结算共用同一编辑逻辑. 姓名不超过50字、详细地址不超过120字, 输入有效手机号并选择完整省市区. 已有地址可直接修改保存, 不强制重新选地区. 读取失败先点重新读取地址, 保存失败会保留输入并释放按钮, 不自动重复提交; 切换账号会清空上一账号的编辑内容.

结算页面读取失败时先重新读取, 确认商品、地址及服务端金额后再提交. 订单创建成功后进入统一付款页; 如跳转失败, 使用“继续付款”或从我的订单进入同一订单, 不重新创建订单. 切换账号或离开页面后不会根据旧响应跳转付款.

意见反馈: 选择反馈类型, 填写1到500字内容及有效手机号. 提交失败保留输入, 可确认后重试; 提交期间不重复发送, 切换账号后不显示上一账号的成功结果.

手机号绑定: 在个人中心进入关联手机号, 输入手机号并获取六位短信验证码. 验证码仅用于本次请求对应的手机号.

商品评价: 打开已确认收货的本人订单, 从对应商品进入评价. 评价提交后进入审核, 返回订单详情时刷新评价入口.

开发环境安装只使用当前完整初始化, 不需逐份执行历史SQL. 已安装环境的构建和启动按维护文档操作; 本次源码精简不会自动重建或清空你的现有数据库.

商品评价: 本人已收货商品可以填写1到500字评价, 提交后待审核展示. 网络失败保留正文, 可核对后重试; 发送期间按钮锁定, 成功后不会再次发表.

浏览足迹: 同一商品只显示最新一次浏览, 按日期分组, 下滑继续加载. 读取失败可点提示重试, 长按商品确认后删除该商品全部浏览记录; 此后再次浏览会产生新足迹.
