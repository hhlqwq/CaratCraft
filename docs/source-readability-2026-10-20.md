# 存量源码可读性审阅记录

日期: 2026-10-20. 本批针对购物车前后端及其调用契约进行职责、命名和状态审阅. 全量格式门禁继续生效, 此记录不表示整个仓库的历史注释和设计均已审阅完毕.

## 已修改

- 全量原生小程序统一对象方法简写, 增加ESLint规则防止旧函数属性写法重新混入. 本项只统一方法声明语法, 不宣称其他页面的复杂逻辑已经完成语义重构.
- 原生购物车页面采用统一方法语法及异步错误处理, 移除`that`别名、多层重复回调和只剩注释的空回调. 请求、响应应用、选择统计、数量修改各有明确职责及中文说明.
- 将服务端结算选择`checked`和本地删除选择`editChecked`分开. 切换编辑、全选、数量更新和删除后, 从同一份新列表计算选择状态, 不依赖视图渲染时机.
- 数量变更使用后端要求的JSON请求体. 原实现发送表单并提前修改本地数量, 失败可能让界面显示未保存的数量. 本批改为服务端成功后更新数量及金额, 请求期间阻止重复操作.
- 加载、保存、失败与重试有明确提示. 页面离开清空私人列表, 请求同时核对页面代次及令牌, 旧账号迟到响应不会回填新页面.
- 后端规格展示查询及规格快照写入收敛到共享方法, 修复换规格使用字符串而非规格ID数组查询、市场价误写零售价、无规格产品残留旧规格名称等问题. 空规格写入非null空值以适配现有MyBatis更新策略.
- 合并已有规格的数量也限制为1到9999, 防止分次新增或更换规格绕过接口上限. 批量勾选只接受0或1.
- 移除勾选操作后无效的多层循环及无关行回写, 移除读取优惠券时查询后丢弃的购物车数据、无用依赖和原始类型集合. 结算预览仍由现有计价服务读取当前规格价格并校验优惠券.
- 明确控制器、应用服务、持久化接口及实现的职责注释, 保留原始作者和版权声明. 公共路由和响应字段保持兼容, 不重命名历史数据库字段.
