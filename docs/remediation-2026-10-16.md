# 2026-10-16 整改与交付说明

本轮处理原审查台账剩余的交易、定制、库存、评价、工程规范与后台体验问题. 原审查文件保留整改前事实, 当前状态以`remediation-status.json`为准. 代码修复、隔离测试通过、真实外部服务验收是三个不同阶段; 本轮没有重启现有业务容器或修改业务数据库.

## 交易与售后

- A018/A019: 退款申请先审核, 使用稳定退款号及数据库租约进行查单与补偿. 微信受理后只显示处理中; 同号、同金额且查单成功后才完成本地退款. 已收货订单可以进入售后审核, 已发货/已收货退款不自动增加实物库存. 异常申请保留人工处理状态并继续查单, 不自动重新发起另一笔退款.
- A023/A025/A026: 下单意图摘要和用户级提交键随订单持久化, 重复提交返回原订单, 不同意图复用同一键被拒绝. 立即购买使用本人独立UUID上下文, 30分钟过期, 多个商品页互不覆盖. 结算与提交共用规格、库存、优惠券及金额计算, 提交金额变化要求重新确认.

商家在订单页的“退款售后”中填写审核说明. 审核通过不代表到账. 已发货售后须由商家确认退货或免退货安排; 系统不会据退款成功猜测实物已回仓. 真实微信退款、异常银行渠道及商户平台人工处理仍需商户环境验收.

## 定制、材料与历史

- A028/A029/A032: 新建或导入材料初始化零库存, 不重置已有余额; 替换导入按稳定代码更新, 原材料停用而不物理删除. 盘点提交原余额做比较更新, 余额已被销售修改时拒绝覆盖, 库存变更与流水在同一事务中提交.
- A033: 商家可配置每件耗用量、单位、互斥材料及必需搭配. 报价与下单均由服务端校验. 订单冻结材料BOM, 取消时按原稳定代码及原数量恢复, 不按后来修改的配置回补.
- A038: 继续编辑更新原草稿ID和版本, 并发旧版本保存被拒绝; 我的设计支持本人草稿归档. 报价快照冻结图层、顺序、名称和用量, 列表按冻结图层合成缩略展示, 不再统一回退为同一logo. 当前采用图层预览, 不生成写实成品照片.
- A039: 导入模板选择当前实际商品, 包含珍珠、链材和尾扣, 默认停用. 配件导入后先填写真实图片、价格及实际库存, 再启用定制商品. 未配置完整的必选材料不能发布.
- A063/A079: 工单、设计、库存分页; 只批量读取当前页关联数据. 工单展示冻结BOM、刻字与图层, 合法动作由服务端共享状态图返回, 退款冻结后不再提供制作动作. 工单流转要求备注, 日志保留操作人和前后状态. 超时订单分批有界扫描并输出进度.

`materialParams`规则示例:

```json
{
  "stockQuantity": 2,
  "stockUnit": "颗",
  "incompatibleWith": ["clasp:small-clasp"],
  "requires": ["chain:chain-18k"]
}
```

这里的代码只是规则格式示例, 不能替代商家的实际可生产规则. `stockQuantity=0`表示不消耗库存的虚拟选项. 当前每种组件类型选一项, 需要多种不同配件时分别建立类型并配置依赖; 同种材料可设置单件耗用量大于1. `priceDelta`表示该配置项整件的加价, 不按耗用单位重复乘价. AI推荐长度是搭配建议, 未与商家长度BOM模型绑定前不会据此自动改写物理耗用量.

## 用户、目录与接口

- A046/A074: 移除未使用的账号注册、密码重置、小程序旧登录页面及不符合社区定位的专题评论入口. 移除公开无密码注册后端入口和旧工具链配置; 保留仍在使用的商品评价与内容展示路径.
- A048/A049: 公共评价列表、计数及商品详情摘要统一使用审核通过过滤; 只输出昵称、头像等必要展示资料. 提交必须为本人已收货商品, 首评奖励先判断已有记录再插入, 与评价在同一事务中保存, 重复评价不能重复领奖.
- A050/A062: 购物车、目录、退款与配置逻辑进入应用服务, 控制器负责身份、参数和响应适配. JSON业务失败同步使用对应HTTP状态, 包括400/401/403/404/405/409/500; 旧页面保留对可恢复业务错误的响应处理.

## 工程与后台体验

- A067: Vue2、Element UI旧运行代码、webpack4、Gulp、Babel6和ESLint3已从安装链移除. 当前使用Vue3.5.44及官方迁移兼容构建、Element Plus2.14.7、Vite8.3.4、Vue Router4、Vuex4和Axios1.20.0. 运行环境统一为Node22.13至24.x、pnpm9.15.9. 原有业务组件暂保留明确的兼容模式, 后续可逐页迁移, 不能直接删除兼容配置.
- A068: 本轮Java代码按Google Java Format整理; 完整管理端业务源码通过当前ESLint检查. 函数说明、第三方排除边界及检查入口见`source-style.md`.
- A077/A078/A080/A086: 首页改为真实权限范围内的商家待办, 监控独立入口. 演示标签仅用于演示商品. 修正CPU与磁盘字段标注, 同卷挂载去重, 容量增加数值一致性检查. 后台侧栏、弹窗、表单与表格支持624/1280像素布局, 图标按用途重新绘制. 小程序补充底部安全区和设计操作按钮换行.

构建当前仍有较大公共组件包的体积提示, 不属于构建失败; 已移除无页面使用的ECharts及停止维护的CryptoJS. 管理端AES使用浏览器原生Web Crypto保持既有协议兼容, 固定公开密钥不能替代HTTPS保护.
