# CaratCraft · 克拉匠造

面向珍珠商城与项链定制的微信小程序和商家工作台. 支持商城、二维DIY、社区、我的, 以及材料配置、设计快照、订单、工单和售后. 当前技术为Java21/Spring Boot、MySQL/Redis、原生Vue3/Element Plus/Vite及原生微信小程序.

## 本地入口

本项目处于未发布开发阶段, 本地数据库和Redis可丢弃. 正常启动发现旧开发卷凭据或结构失配时, 自动重建本项目数据库/缓存并重试一次, 无需手工迁移旧开发数据; 不影响其他项目或上传素材卷. 该入口不适用于上线后的真实数据环境.

环境入口脚本统一放在`deploy/scripts/`目录, 根目录不保留重复入口. Windows客户取得完整项目文件后, 只需安装并启动Docker Desktop(Linux容器及Compose V2), 进入`deploy/scripts/`目录后依次双击构建和启动脚本:

1. `deploy/scripts/build-local-test.cmd`: 从国内镜像及依赖源下载, 在容器内安装依赖并编译前后端. 下载或编译失败立即退出, 修复网络或构建问题后重新运行.
2. `deploy/scripts/start-local-test.cmd`: 自动生成首次配置, 启动MySQL、Redis、后端和管理端, 初始化空数据库并等待健康检查通过.

不需要在客户电脑安装Git、Node、Java、Maven、pnpm或Codex, 不需要准备本机依赖缓存或编译产物. Windows启动支持PowerShell5.1/7, 配置统一按UTF-8生成和读取; 已有.env不会自动覆盖. 启动按失败阶段保留原始错误, 诊断不覆盖根因; 仅修改宿主机启动脚本不再触发镜像重建. 管理端默认地址为`http://localhost:8888`. 详细说明见[联网构建与客户启动](docs/项目维护文档.md#联网构建与客户启动). 当前开发数据以现有初始化源码为准; 真实数据保留与升级仅在上线后执行.

当前源码与验证状态统一见[剩余开发与验收收尾](docs/项目开发文档.md#812-剩余开发与验收收尾), 历史交接见[换机交接入口](docs/项目开发文档.md#810-换机交接与续接入口). 前轮已完成商品、定制、交易及配套功能整改和对应回归; 本轮已统一DIY四类材料并补齐112项停用候选, 207项Java、175项Node、34项Python及九组真实HTTP通过. 小程序协议页真实编译错误已修复, 43个WXML、48个WXSS通过官方编译, 现有IDE重新编译后首页正常显示(0错误、5警告, 警告未逐项核实). 最新材料代码独立镜像内九组HTTP及管理端19个静态资源核对亦通过, 未部署业务实例. 详细边界见开发文档8.13及机器证据.

验证镜像使用已有运行时与当前产物禁网封装, 未替换业务实例. 源码和应用包从干净提交导出, 以忽略目录.tools/copyright/release中的清单和SHA256为准. 微信真机、真实支付退款、正式AI及生产发布单独验收; 已授权的无调用旧锁、规格工具和模拟XML已删除; 当前材料目录与编译结果见开发文档8.13.
