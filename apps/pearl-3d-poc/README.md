# CaratCraft 珍珠项链 3D 样机

当前预 Alpha 为 **3.0.0-0.2**，对应 **v3.0.0 / R3** 技术验证。这个目录是独立微信小程序项目，启动页为 `pages/necklace/index`。

## 导入和体验

1. 在微信开发者工具选择「项目 → 导入项目」，目录选择 `D:\code\github\CaratCraft\apps\pearl-3d-poc`。
2. 选择小程序项目及「不使用 AppID」，编译。项目配置的基础库为 `3.15.1`，如果工具自动选择其他版本，在「详情」中查看并记录实际使用的版本。
3. 首页会显示 44 颗珠子、完整轮廓和金属扣。单指拖动旋转，两指拉伸以中点为参照缩放。轻点一颗珠子，看到墨绿选中环和当前珠径后，可切换到 6、7.5、9 或 10.5 mm。选中项随项链重排保留。
4. 手机上预览时，在开发者工具使用**当前微信账号有预览权限的测试小程序 AppID**。可为预览复制这个独立目录，再在导入时选该测试 AppID。以有权限的同一微信账号登录工具，点击顶部「预览」，手机微信扫码。仓库的游客 AppID 用于本机模拟器。
5. 预览时分别试完整取景、斜转、小幅和较大缩放、相邻珠点选及切换尺寸。初次预览由微信开发者工具生成预览包。页面运行时无需业务服务或外部资源。

页面右上显示样机版本。加载提示超过五秒仍未完成时, 新版会显示失败阶段及「重试」入口。若重试仍失败, 在开发者工具控制台筛选 CaratCraft 3D 并保留第一条错误及基础库版本。

## 实现与验证边界

- 使用原生 `canvas type="webgl"` 和 WebGL 1。项目没有 npm、服务器和外部模型或图片依赖。光泽来自本地 GLSL 的微扰法线、软箱反射、母贝色层和金属着色，画面是程序化样机。
- 几何使用毫米单位表示珠径，依据相邻实际珠心间距重新排布，扣件、环、穿线随轮廓重建。点选使用射线与球体相交，优先选择前方可见珠体。
- 一份共享珠体网格、像素预算及按需帧降低手机负担。切换尺寸复用已分配的扣件和线材缓冲。页面隐藏停止绘制，卸载显式释放缓冲和程序。
- 本轮通过已安装的微信官方 WCC/WCSC 编译及桌面 Edge WebGL 验证。用户在微信开发者工具发现 3.0.0-0.1 持续显示加载。3.0.0-0.2 通过首帧、超时、重试和隐藏退出回归。此修复在微信模拟器中的实际渲染、双指手势、手机扫码和设备性能仍待验证。
- 工具调试控制台记录 `[CaratCraft 3D] 首帧提交` 与 `[CaratCraft 3D] 连续手势帧`。前者以页面加载到 WebGL 命令提交计时，后者用于观察持续手势的实际帧间隔。几何缓冲字节数只统计代码明确上传的数据。手机总内存和 GPU 内存须通过设备可用的性能分析工具另测。

- 桌面辅助验证一例使用 Edge 的 SwiftShader 软件渲染，缓冲尺寸 752×1154，首帧提交约 1.57 秒，64 个帧间隔平均约 6.6 FPS，P95 约 217 ms。这个软件渲染路径存在明显卡顿。几何 GPU 缓冲约 177 KiB，属于已知分配量，设备内存和手机帧率待测。
